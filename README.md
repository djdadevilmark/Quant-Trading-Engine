# Quant-Trading-Engine

High-frequency cryptocurrency trading engine using statistical arbitrage and ML.

## Project Structure
- `core-cpp/compute_node.cpp` — Primary C++ service module
- `src/` — Supporting runtime configuration, retry, and cache utilities
- `tests/` — Unit tests and boundary checks
- `docs/` — Architecture and operational notes
